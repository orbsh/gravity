## Open items

- [x] The declaration door moved into schematic (2026-11-26): `schematic::plan_from_declaration` is the check and `PlanReadError::OldShape` its wording, so every host refuses the old ordered-array shape with one sentence; `booth::schedule_plan` is now that call with the door's own name in front, and keeps the store fetch. The model is schematic's — an independent engine — so the sentence belongs there rather than in one host. Later, if splice matures, its own engine is expected to replace schematic — which is why splice has to stay compatible with schematic's model rather than define a second one.

- [ ] A duplicated patch frame: one patch delivered N times per screen — seen 2026-11-05 in a six-connection probe, re-measured 2026-11-20 in a clean venue with ONE tab (`SMOKE_PAGE=1 scripts/smoke-venue.sh`): turn 1 draws 2 deltas + `opened` + `done`, turn 2 draws 2 deltas + `done`, nothing twice and nothing carried over. prism's fan-out is one delivery per `/channel` CONNECTION (pinned by `ui_leg::one_emit_draws_exactly_one_frame_however_much_was_said_before`), so a frame that arrives N times means N connections for one screen — the SCREEN's connection management, not the venue. The page this repo can drive is the one `smoke-venue.sh` writes for itself (`$ROOT/page.py`, an inline script speaking the wire over `websockets`); a real screen is another product — reflux, the producer/host/page stack that pins fluxen's renderer bundle, the same bundle prism serves at `/` (prism ADR-0017 §10) — and nothing in this repo depends on it. Parked here until such a page can be driven for real
- [ ] `scripts/smoke-venue.sh` is not a gate: it passes end to end (provider, k10r, prism, a real effector node, a code row run on that node) but no workflow references it, and this repo has no CI to reference it from
- [x] ADR-0007's model row promised `affinity` with no such field — settled the other way (2026-11-20): the affinity key is the SESSION, so it is not a column, and the ADR no longer lists it
- [x] Cancellation is a marker the turn polls at its chunk boundary — 2026-11-09 — ADR-0008, aura ADR-0047, effector's `Frame::Interrupt`
- [x] `run` for a script that belongs to no skill — 2026-11-09
- [x] The CLI's credential for an unattended caller is a TOKEN (`venue.token_env`) — 2026-11-21, ADR-0002: the venue mints one from the account's password (`POST /admin/tokens`, login over HTTP) and the client presents it on the dial with no login frame, so a loop logs in nowhere. A config names `token_env` or `username` + `password_env`; neither is refused at first sight, and a token the venue does not know is an auth failure (exit 3), not a turn run as nobody

- [x] The transcript has a BUDGET — 2026-11-25, ADR-0017: `models` gains one cold field `context_window` (a window is a property of the model, not of the deployment), the request asks for usage only when a window is declared, and the decoder hands the number to the done envelope. Three lines, each with a reason: `0.5` (the tier line — collapse finished tool rounds at the price boundary, not near the top), `0.8` (trim the oldest history rows to the last 8; the store has them), `0.95` (do not send the round: file the row, close the turn, fail with that text). It is ONE ROUND LATE by construction — usage describes the request that just ended — and that is stated in the ADR rather than estimated around. No tokenizer, no persistence (a `usage` row needs a machine kind, which is k10r's decision); the reading is one stderr line per evaluation. Verified end to end: the smoke's stub now reports usage, and the CLI's turns print `[gravity] context 2929/1048576 (0%) · Free` → `3190/…` as the transcript grows

- [x] The close is CHECKED against the channel — 2026-11-25, ADR-0018: `keep` is a claim, and nothing had ever asked whether the named rows exist. `TurnLog::verify` reads the channel (history, not the projection — an OPEN row is visible) and the close carries the verdict in its own record (`""` normally, `unverified: N row(s) …` otherwise). An unverified turn does NOT fail — "it failed" and "it cannot be trusted" are different sentences, and the record is where the second one goes — but a channel that cannot be read back IS a failure: books that cannot be checked are not closed. One GET per turn, zero tokens, no new store door. Cost of the shape: `missing_rows` (5 cases) — plus the smoke's turns now close through this read, so a broken read path fails a turn instead of hiding
